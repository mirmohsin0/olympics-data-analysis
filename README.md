##  Olympics Games Data -- Olympics Analysis Web App

This project uses historical athlete and event data to provide insight into Olympic participation, medal performance, countries, athletes and other historical trends

## Dataset
The dataset used in this project is:

120 years of Olympic History: Athletes and Results 

Dataset link: https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results

## Running the Project Locally
1. Clone the Repo
git clone Your_Github_Repository_URL

2. Navigate to the project folder 
cd olympics-analysis-webapp

3. create a virtual environment 
python -m venv venv 

4. Activate the virtual environment 
venv\scripts\activate 

5. Install Dependencies
pip install -r requirements.txt

6. Run the application
streamlit run app.py
